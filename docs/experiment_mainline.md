# FinScope 实验主线（冻结版）

本文档是后续实现、校准和实验的唯一执行口径。任何脚本或结果若与本文冲突，先修正实现，不沿用旧结果。

## 1. 研究问题

FinScope 研究长程金融 Agent 任务中的累积隐私风险：真实证券、持仓和订单不能暴露给外部模型，但受保护实体仍需贯穿多 Agent、跨轮次和跨交易日决策链，最终在本地准确恢复为可执行的金融对象。

FinScope 是运行在可信本地的专职隐私 Agent，基座模型固定为 **Qwen3.5-4B**；当前正式任务模型固定为 **Qwen3.8-27B**。本地 Agent 负责动态披露、句柄状态维护、真实对象恢复和交易前校验，外部任务模型始终看不到真实身份及映射表。

## 2. 主方法

### 2.1 动态披露 P-level

每次调用外部模型前，本地 Agent 根据角色、任务阶段、字段风险和历史披露状态选择 P1-P5。P-level 控制“本轮披露多少语义”：低风险研究阶段保留必要推理语义，高风险持仓、订单和执行阶段提高保护等级。P-level 不决定句柄寿命，也不等同于阈值 T。

### 2.2 本地双状态

- 隐私暴露状态：匿名句柄出现次数、持续交易日、可见角色、关联行情、关联交易行为、资产数量和高风险事件。
- 任务依赖状态：当前是否仍有研究结论、风险判断或待执行动作依赖旧句柄。

请求次数和交易日数只是暴露状态特征，不直接被定义为隐私泄露量。

### 2.3 无训练攻击风险查表

攻击器固定为 **Qwen3.5-4B 零样本攻击器**，不训练分类器、回归器、Ridge 或任何风险模型。在 StockBench 开发集上逐级提供 K1-K4 公开先验；K4 包含候选类型、证券主表及静态属性、公开历史行情和跨轮行为，是阈值校准采用的最强公开先验。

对不同暴露状态截取匿名轨迹，实测身份重识别 `ReID@1` 和跨轨迹关联 `Link AUC`，并计算：

`R = max(ReID@1, 2 * |Link AUC - 0.5|)`。

成功的 K4 攻击观测按暴露强度排序，形成确定性的经验风险查找表。在线阶段仅用当前本地暴露状态查表或单调插值获得风险；禁止拟合或训练风险估计器。

### 2.4 阈值 T 与自动替换

T 只控制“何时更换匿名句柄”：

- `R < T`：保留当前句柄；
- `R >= T` 且没有未完成依赖：立即替换；
- `R >= T` 且仍有任务依赖：标记待替换，在最近安全检查点执行。

替换时，本地保留真实证券、持仓和任务状态，关闭旧外部会话，分配新句柄，并只向新会话发送完成后续任务所需的最小状态。旧对话和新句柄不得同时发送给外部模型，避免直接泄露新旧映射。

## 3. T 的确定流程

1. 仅使用 StockBench 开发集和 Qwen3.8-27B，扫描 `T={0.2, 0.4, 0.6, 0.8}`。
2. 每个候选均使用同一份 Qwen3.5-4B、K4 经验风险查找表，运行完整开发轨迹并重新执行 K4 攻击。
3. 先做非退化检查：零交易、有效率或执行成功率不达标的候选直接淘汰；不得因参考收益为负而把“不交易”判为零损失。
4. 再约束 Return、Sharpe、Valid、执行成功率和交易行为相对同方法无替换参考的最大效用损失。
5. 在满足全部效用约束的候选中选择 R 最低者；若风险相同，选择额外开销更小者。
6. T 只在开发集选择一次，写入校准产物后冻结；测试集和正式主表严禁再次调参。

旧启发式攻击得到的 `T=0.2`、旧 Ridge 产物和允许零交易通过的扫描结果全部作废。

## 4. 实验执行顺序

1. 完成 Qwen3.5-4B K1-K4 零样本公开先验攻击，构建 K4 经验风险查找表。
2. 按第 3 节重新扫描并冻结 T。
3. 运行 Qwen3.8-27B 正式主表：StockBench、NLPCC、FinVault，比较 Vanilla、Deletion、LLM Rewrite、Fixed Alias、Episode Alias 和 FinScope Adaptive。
4. 主表完成后再运行替换机制和支撑实验，不得用补充实验反向调整正式 T。

## 5. 固定的十张论文表

1. NLPCC 主表：验证连续资产配置效用、恢复能力和隐私保护。
2. StockBench 主表：验证长程多 Agent 股票决策中的效用、连续性、恢复和隐私。
3. FinVault 主表：验证多轮金融安全场景的泛化，不宣称其为跨交易日任务。
4. 公开先验攻击：验证 K1-K4 攻击强度及结论在强公开先验下仍成立。
5. 自适应替换与固定周期：比较不替换、固定周期、按任务替换和自适应替换。
6. 替换时机与任务连续性：验证安全检查点能降低替换造成的任务中断。
7. 风险查表与阈值选择：报告开发集候选 T、效用约束、实测攻击风险和最终选择。
8. 本地隐私 Agent 模型选择：仅在开发集比较不超过 4B 的本地模型，正式方案固定 Qwen3.5-4B。
9. 关键组件消融：移除动态披露、暴露记忆、任务依赖、安全检查点、映射缓存等组件。
10. 故障安全实验：测试未知句柄、过期映射、映射冲突和恢复失败时是否阻止错误执行。

公开先验攻击与 T 选择可在论文排版中合并为同一复合表的两个 Panel，但实验口径保持独立。不得额外拆出“匿名轨迹增长”主表。

## 6. 禁止偏离项

- 不训练风险估计器；不使用 Ridge、分类器或回归器代替 Qwen3.5-4B 攻击结果。
- 不把 T 解释为任务长度，也不把 T 与 P-level 合并。
- 不使用测试集选择 T，不用单次主表结果反向修改 T。
- 不允许零交易、全拒绝或任务中断方案通过效用约束。
- 不把 FinVault 描述为跨交易日 Benchmark。
- 未经重新验证，不复用旧启发式攻击、旧校准文件或模拟数据作为真实实验结果。
